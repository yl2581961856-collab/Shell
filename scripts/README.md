# Helper scripts

- `ws_mic_client.py`: microphone streaming client for `/asr/stream`.
- `start_server.sh`: start the FastAPI/WS server via `uvicorn` (Python 3.11 target).
- `bootstrap_py37.sh`: create a local venv on Python 3.7, install deps, and start the server.
- `bootstrap_py311.sh`: create a local venv on Python 3.11, install deps, and start the server.
